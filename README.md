# Physical Computing Project 2026 - IT KMITL

## โปรเจ็กต์ ColorSync 🗿

### วัตถุประสงค์
1. เพื่อให้ผู้เล่นได้ฝึกการสังเกต การจดจ่อ และการจดจำลำดับสีผ่านเกม
2. เพื่อสร้างความสนุกและความท้าทาย โดยผู้เล่นสามารถทำลายสถิติของตนเองหรือผลัดกันแข่งขันกับเพื่อนได้
3. เพื่อพัฒนาเกมบนไมโครคอนโทรลเลอร์ที่เชื่อมต่อเว็บไซต์ผ่าน Wi-Fi สำหรับตั้งค่า แสดงผล และติดตามประวัติคะแนน

### รายละเอียดโปรเจ็กต์
ColorSync เป็นเกมจดจำลำดับสีที่ใช้อุปกรณ์ดังนี้
| อุปกรณ์ | จำนวน | รายละเอียด |
|---|---:|---|
| Arduino UNO R4 WiFi | 1 | บอร์ดควบคุมหลักของระบบ |
| LED สีแดง | 1 | แสดงผลสีแดง |
| LED สีเหลือง | 1 | แสดงผลสีเหลือง |
| LED สีเขียว | 1 | แสดงผลสีเขียว |
| LED สีน้ำเงิน | 1 | แสดงผลสีน้ำเงิน |
| Push Button | 4 | ใช้สำหรับกดเลือกสี |
| Passive Buzzer | 1 | ใช้สร้างเสียงประกอบ |
| Resistor | 4 | ใช้จำกัดกระแสให้ LED |
| Breadboard | 1 | สำหรับประกอบวงจร |
| Jumper Wire | หลายเส้น | ใช้เชื่อมต่ออุปกรณ์ |
| จอ LCD | 1 | สำหรับแสดงเลเวล คะแนน และสถานะเกม

เกมจะสุ่มลำดับสีและแสดงผ่าน LED พร้อมเสียง จากนั้นให้ผู้เล่นกดปุ่มตามลำดับที่เห็น หากตอบถูกครบ ระบบจะเพิ่มสีหนึ่งตำแหน่งต่อท้ายลำดับเดิมในรอบถัดไป หากกดผิดหรือหมดเวลาตอบ เกมจะสิ้นสุด โดยนับคะแนนจากจำนวนรอบที่ตอบถูกครบ

ผู้เล่นสามารถเปิดเว็บไซต์ผ่านอุปกรณ์ที่เชื่อมต่อ Wi-Fi เครือข่ายเดียวกับบอร์ด เพื่อกรอกชื่อเล่น เลือกความเร็ว เริ่มเกม และดูสถานะกับคะแนน เว็บไซต์จะบันทึกประวัติและคะแนนสูงสุดแยกตามระดับความเร็วไว้ในเบราว์เซอร์ ทำให้ผู้เล่นเปรียบเทียบผลของตนเองหรือผลัดกันแข่งขันกับเพื่อนบนเครื่องเดียวได้

### ฟีเจอร์ที่วางแผนพัฒนา
- เกมจดจำลำดับสีที่เพิ่มความยาวของลำดับเมื่อผ่านแต่ละรอบ
- แสงและเสียงตอบสนองต่อการกดปุ่ม
- เว็บไซต์สำหรับกรอกชื่อเล่น เลือกความเร็ว (4 ระดับ) และเริ่มเกม
- การแสดงสถานะ รอบปัจจุบัน และคะแนนบนเว็บไซต์
- ประวัติการเล่นและคะแนนสูงสุดแยกตามระดับความเร็ว
- การแข่งขันแบบผลัดกันเล่นบนเครื่องเดียว

### วิธีเล่น
1. เปิดเว็บไซต์และกรอกชื่อเล่น
2. เลือกระดับความเร็วแล้วเริ่มเกม
3. สังเกตและจดจำลำดับไฟที่แสดง
4. รอให้แสดงลำดับครบ แล้วกดปุ่มตามลำดับที่เห็น
5. เมื่อตอบถูกครบ จะได้รับ 1 คะแนนและเข้าสู่รอบถัดไป โดยเพิ่มสีอีกหนึ่งตำแหน่ง
6. หากกดผิดหรือหมดเวลาตอบ เกมจะสิ้นสุดและแสดงผลคะแนน
7. หากแข่งขันกับเพื่อน ให้ผลัดกันเล่นโดยเลือกระดับความเร็วเดียวกัน แล้วเปรียบเทียบคะแนน
