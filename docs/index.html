01 / THE PROJECT

บทคัดย่อ Abstract

โครงงาน ColorSync เป็นเกมจดจำลำดับสีที่พัฒนาด้วยไมโครคอนโทรลเลอร์ Arduino UNO R4 WiFi ร่วมกับเว็บไซต์ เพื่อให้ผู้เล่นได้ใช้การสังเกต การจดจ่อ และการจดจำลำดับผ่านกิจกรรมที่สนุกและเข้าใจง่าย ระบบแสดงลำดับสีด้วย LED และเสียงจาก Buzzer จากนั้นผู้เล่นกดปุ่มตามลำดับที่เห็น เมื่อตอบถูกครบจะได้ 1 คะแนนและเพิ่มสีหนึ่งตำแหน่งในรอบถัดไป เกมสิ้นสุดเมื่อกดผิด หมดเวลาตอบ หรือผ่านครบทุกรอบ

เกมมีความเร็ว 4 ระดับ เป้าหมาย 5, 7, 10 และ 15 รอบตามลำดับ จอ LCD แสดงสถานะและผลการเล่น ส่วนเว็บไซต์ใช้กรอกชื่อ เลือกความเร็ว เริ่มเกม และดูคะแนน โดยบอร์ดให้บริการหน้าเว็บผ่านเครือข่าย Wi-Fi เดียวกัน ระบบบันทึกประวัติในเบราว์เซอร์และรองรับการแข่งขันแบบผลัดกันเล่นสองคนด้วยความเร็วและลำดับสีเดียวกัน โครงงานนี้นำการเขียนโปรแกรม ระบบฝังตัว และการพัฒนาเว็บมาประยุกต์ใช้ร่วมกัน

Read the English abstract

ColorSync is a sequence-memory game built with an Arduino UNO R4 WiFi and a web interface. LEDs and a buzzer present a color sequence, and players repeat it using physical buttons. Each completed round earns one point and adds one color to the next round. Four difficulty levels offer targets of 5, 7, 10, and 15 rounds. An LCD displays game status and results. The board serves a local website for player names, difficulty selection, game controls, and scores. Browser storage keeps play history, while a two-player mode compares results using the same difficulty and sequence. A browser-only demo is also available. The project combines embedded programming and web development in an interactive memory activity.

ปุ่มกดส่งคำตอบให้บอร์ดตรวจสอบ แล้วแสดงผลผ่าน LED เสียง และ LCD เว็บไซต์รับสถานะผ่าน HTTP และใช้ตารางเวลาของรอบช่วยแสดงแสงตามบอร์ด ความตรงกันของแสงยังขึ้นกับความหน่วงของเครือข่าย

ดูขาที่ใช้ต่อวงจร

LED: D2, D4, D6, D8
ปุ่มสี: D3, D5, D7, D9 ต่ออีกด้านลง GND ใช้ INPUT_PULLUP
Buzzer: D12
LCD I2C: SDA=A4, SCL=A5, address 0x27
LED แต่ละดวงต้องผ่านตัวต้านทาน และทุกอุปกรณ์ใช้ GND ร่วมกัน

เล่นจาก GitHub Pages กับเล่นบนบอร์ดต่างกันอย่างไร?

เปิดเว็บจาก IP ของบอร์ด

โหลดโค้ด ColorSync จากชุดดาวน์โหลดเฟิร์มเเวร์ แล้วเปิด IP ของบอร์ดด้วยอุปกรณ์ใน Wi-Fi เดียวกัน

  1. ใส่ Wi-Fi ใน secrets.h แล้วอัปโหลด
  2. เปิด Serial Monitor ที่ 115200 baud เพื่อดู IP
  3. เปิด http://IP-ของบอร์ด ในเบราว์เซอร์
หากเปิดเว็บจาก Live Server ให้เลือกทดลองเล่น เมื่อต้องการเล่นกับบอร์ด ให้เปิด IP ที่แสดงใน Serial Monitor

เล่นจริง : ดูสัญญาณไฟจากหลอดไฟหรือหน้าเว็บก็ได้
